## Version Release v5.0.0 MC-1.21.1

### Additions
- Added useful commands for testing (all of these require permission level 4)
  - Added /rl_heal, this adds a float value to the user's health
  - Added /rl_hunger, this adds an integer value to the user's hunger
  - Added /rl_saturation, this adds a float value to the user's saturation
  - Added /rl_setname, this sets the name of a targeted entity
  - Added /rl_dyegive, this gives every dyed block with this suffix
