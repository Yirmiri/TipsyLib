## Version Release v5.0.7 MC-1.21.1

### Misc Additions
- Added `RLTrade`, an **experimental** system that allows registering villager trades without the hassle of doing it per modloader
  - Use `professionTrade` to register a normal Villager trade, and `wanderingTrade` to register a Wandering Villager trade
  - Contains a shortcut method to register custom structure locator maps
  - Code provided by/based on VectorLib's `VectorTrade` by @TheArtyrian (GitHub)
