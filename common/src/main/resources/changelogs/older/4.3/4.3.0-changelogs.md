## Version Release v4.3.0 MC-1.20.1

### Additions
- Added a recipe type that checks for if a mod is loaded before loading the recipe. To use you must set the `"type"` field in your recipe 
JSON to `"runiclib:mod_loaded_condition"`. With this recipe type there are 2 additional fields, `"modid"` (the id of the mod
that should be loaded before loading this JSON) and `"wrapped_type"`, the actual recipe type to (for example: `"minecraft:crafting_shaped"`
is the recipe type used for basic crafting table/inventory crafting recipes). 
  - If the mod is not loaded then it will ignore this recipe entirely. 
  - This was primarily created for compatibility as it will ignore JSONS for mods that are not loaded, (normally those 
  would flood the log with errors for missing item ids if other modded items are used in the recipe).
