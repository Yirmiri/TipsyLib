## Version Release v4.3.3 MC-1.20.1

### Notes
- Updated LICENSE, please read the updated LICENSE if this affects you

### Additions
- RLPlatformHelper can now get whether the environment is client-sided or running datagen
- Added registerWoodType in RLRegistryHelper, this takes in a string id for the wood type and registers it
- Added RLFurnaceFuelRegistry which provides a register method that takes in an item to burn and the amount of time in ticks as an int
to burn for, this method will create a fuel for Furnaces
- Added RLClientHelper and the ability to load services on the client only
- RLClientHelper introduces registerBlockRenderType and registerParticleProviderType to allow creating the corresponding things
within a common workspace
